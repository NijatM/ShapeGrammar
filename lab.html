Save the current drawing, rule and undo/redo history on this browser, or import a downloaded file. Restore and import replace the open workspace after the file passes validation. Download your current work first if you want to keep both.

    A small mathematical model

    Same transformation.
    Both sides of the rule.

    S′ = (S − t(A)) + t(B)

    Apply a rule when t(A) is a part of S. Collinear pieces fuse, so a part can span earlier strokes. A point where two lines cross contributes no common line segment.

    Inspired by George Stiny’s shape formalism and Terry Knight’s work on emergence, ambiguity and learning through making. This lab uses unlabelled straight lines, exact rational coordinates and a finite transformation menu.
