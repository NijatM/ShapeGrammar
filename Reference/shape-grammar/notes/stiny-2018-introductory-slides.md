## Central premise

A rule can match an embedded shape even when that shape differs from the objects originally drawn. Fusion permits later rules to divide the result differently. [1](https://ocw.mit.edu/courses/4-540-introduction-to-shape-grammars-i-fall-2018/e30a7279edca537998b17385065593f4_MIT4_540F18_lectureslides.pdf) [2](https://ocw.mit.edu/courses/4-540-introduction-to-shape-grammars-i-fall-2018/e30a7279edca537998b17385065593f4_MIT4_540F18_lectureslides.pdf)

## How the demonstration works

## The rule-application mechanism

For A→B in host C, find t(A)≤C, then calculate (C−t(A))+t(B). The same transformation t places both sides; after fusion, the next match can select different parts. [3](https://ocw.mit.edu/courses/4-540-introduction-to-shape-grammars-i-fall-2018/e30a7279edca537998b17385065593f4_MIT4_540F18_lectureslides.pdf)

## A practical reading task

Trace a part that crosses earlier drawing boundaries, apply one rule, then redraw a different decomposition of the result. Compare the geometry with its description tree. [1](https://ocw.mit.edu/courses/4-540-introduction-to-shape-grammars-i-fall-2018/e30a7279edca537998b17385065593f4_MIT4_540F18_lectureslides.pdf) [2](https://ocw.mit.edu/courses/4-540-introduction-to-shape-grammars-i-fall-2018/e30a7279edca537998b17385065593f4_MIT4_540F18_lectureslides.pdf) [3](https://ocw.mit.edu/courses/4-540-introduction-to-shape-grammars-i-fall-2018/e30a7279edca537998b17385065593f4_MIT4_540F18_lectureslides.pdf)

## Key terms

- **Schema**: A family of rules obtained by assigning values to variables.
- **Embedding**: Finding a transformed copy as a geometric part.
- **Fusion**: Combining shapes without retaining a required original subdivision.
