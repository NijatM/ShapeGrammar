## The main ideas

A vector space carries addition and scalar multiplication satisfying explicit laws. A linear map preserves both. Such a map need not be invertible: projection can preserve linear structure while losing information. [1](https://jheffero.w3.uvm.edu/linearalgebra/book.pdf) [2](https://jheffero.w3.uvm.edu/linearalgebra/book.pdf)

## How the examples teach the distinction

The text verifies closure for a line through the origin and checks projection directly. A nonzero constant offset gives a contrasting map that fails linearity. Definitions therefore distinguish superficially similar formulas. [1](https://jheffero.w3.uvm.edu/linearalgebra/book.pdf) [2](https://jheffero.w3.uvm.edu/linearalgebra/book.pdf)

## Why matrices enter

A linear map is determined by its images on a basis. Express those images in the target basis and place their coordinate columns in a matrix; multiplication then computes image coordinates. [3](https://jheffero.w3.uvm.edu/linearalgebra/book.pdf)

## Connection to symmetry

Keep the abstract transformation separate from its matrix in a chosen basis. This prepares for group representations, where transformations must compose consistently and be invertible, not merely be arbitrary matrices. [2](https://jheffero.w3.uvm.edu/linearalgebra/book.pdf) [3](https://jheffero.w3.uvm.edu/linearalgebra/book.pdf)

## Key terms

- **Linear map**: A map preserving addition and scalar multiplication.
- **Basis**: Independent vectors spanning the space.
- **Matrix representation**: A coordinate description relative to specified bases.
