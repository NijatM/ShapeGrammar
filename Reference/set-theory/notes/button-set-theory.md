## What this book is about

The selected route asks both how sets behave and which collections may legitimately be sets. It begins with familiar membership-based reasoning, exposes a contradiction in unrestricted set formation, and motivates a staged picture for more disciplined foundations. [1](https://st.openlogicproject.org/settheory-screen.pdf) [3](https://st.openlogicproject.org/settheory-screen.pdf)

## Premise and main claims

Extensionality says sets with exactly the same members are identical; it does not guarantee that every description defines an existing set. Russell’s proposed collection of all non-self-membered sets yields a contradiction when tested for membership in itself. [1](https://st.openlogicproject.org/settheory-screen.pdf)

## Method of argument

The text separates definitions, existence assumptions and logical consequences. In Cantor’s argument, assume a bijection g from A onto its power set and form D={x∈A:x∉g(x)}. No proposed image g(y)=D can survive the membership test at y. [2](https://st.openlogicproject.org/settheory-screen.pdf)

## Results and interpretation

The singleton map injects A into its power set, while diagonalization rules out a bijection: the power set is strictly larger. Later, cumulative stages motivate forming sets from already available members rather than collecting everything described by an arbitrary predicate. [2](https://st.openlogicproject.org/settheory-screen.pdf) [3](https://st.openlogicproject.org/settheory-screen.pdf)

## What this does not establish

Avoiding Russell’s particular contradiction does not by itself prove an entire axiom system consistent. The stage story is conceptual motivation. The formal axioms and their later consequences require their own careful reading. [3](https://st.openlogicproject.org/settheory-screen.pdf)

## Why read it alongside the app

Use this when elementary set notation starts feeling deceptively unrestricted. Keep three questions separate: what a collection would contain, whether it exists as a set, and how its size compares with another set. [1](https://st.openlogicproject.org/settheory-screen.pdf) [2](https://st.openlogicproject.org/settheory-screen.pdf) [3](https://st.openlogicproject.org/settheory-screen.pdf)

## Key terms

- **Extensionality**: Set identity determined by membership.
- **Unrestricted comprehension**: The inconsistent proposal that every predicate determines a set.
- **Diagonalization**: Building an object that differs from every proposed representative.
